# rastgele-varolus-krizi-ureticisi

## Bu Ne?

Her çalıştırmada sana rastgele bir varoluşsal kriz üreten program. Çözüm yok, sadece sorular. Hayatını sorgulatır, sonra da unutursun.

### Nasıl Kullanılır

```bash
python kriz.py
```

Tek seferlik kriz. Tekrar çalıştır, yeni kriz.
